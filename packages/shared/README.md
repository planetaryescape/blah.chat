# @blah-chat/shared

Shared, framework-agnostic utilities and constants used across blah.chat apps and services.

## Install

```bash
bun add @blah-chat/shared
```

## Quickstart

```ts
import { toTitleCase } from "@blah-chat/shared/utils";

void toTitleCase;
```

## API

- `@blah-chat/shared`: main entrypoint
- `@blah-chat/shared/utils`: string/date/tag helpers
- `@blah-chat/shared/byod`: BYOD schema metadata + helpers
- `@blah-chat/shared/preferences`: preference keys/defaults
- `@blah-chat/shared/limits`: shared limits
- `@blah-chat/shared/integrations`: integration metadata
- `@blah-chat/shared/canvas`: canvas diff helpers

## Runtime

- ESM only
- Framework-agnostic
